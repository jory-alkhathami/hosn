# حصن | HOSN 

**Fraud Intelligence Prototype** — نموذج أولي يوضح فكرة ربط الإشارات السلوكية والمعاملاتية عبر رحلة العملية المالية، بدل تقييم كل حدث بشكل منفصل.

## فكرة المشروع
حصن 360 يعرض كيف يمكن لنظام مكافحة الاحتيال إعادة تقييم المخاطر مع وصول أحداث جديدة، وشرح العوامل التي رفعت درجة المخاطر، ثم اقتراح استجابة مع إبقاء القرار النهائي للمحلل البشري.

> هذا المستودع نموذج إثبات مفهوم (PoC). جميع الأسماء والبيانات ودرجات المخاطر والأوزان والسيناريوهات تجريبية، ولا تمثل نموذجًا مصرفيًا معتمدًا أو بيانات عملاء حقيقية.

## ما الذي يتضمنه النموذج؟
- لوحة نظرة عامة للحالات قيد المراقبة.
- قائمة حالات بمستويات مخاطر مختلفة.
- محاكاة تفاعلية تظهر الأحداث تدريجيًا.
- Risk Score قابل للتفسير مع مساهمة كل إشارة.
- مركز تنبيهات.
- صفحة توضح منطق محرك المخاطر التجريبي.
- سجل قرارات يوضح مبدأ Human-in-the-loop.

## التشغيل محليًا
يتطلب Python 3.

```bash
py -m pip install -r requirements.txt
py app.py
```

ثم افتح:

```text
http://127.0.0.1:5000
```

على macOS/Linux يمكن استخدام `python3` بدل `py`.

## ملاحظات التطوير
النسخة الحالية تستخدم قواعد وأوزانًا ثابتة لتوضيح تجربة المنتج فقط. قبل أي استخدام فعلي يلزم تصميم نموذج مخاطر ومعايرته والتحقق منه باستخدام بيانات مناسبة، مع متطلبات الخصوصية والأمن والحوكمة والتكامل مع الجهة المالية.
